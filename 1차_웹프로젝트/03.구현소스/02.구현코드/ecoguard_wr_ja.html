非フッ素系防水加工剤(ECOGUARD-WR)

ABOUT PRODUCT

ECOGUARD-WRはPFASおよびAPEOなどの環境有害物質を含まない 環境対応型の非フッ素系防水加工剤です。

150℃前後の低温でも使用可能であり、既存のワックスやシリコン系防水剤よりも 優れた防水性と洗濯耐久性を発揮します。

KEY FEATURES

PFAS、APEOなどの環境有害物質を含まない

低温（150℃）での使用が可能、既存のワックス／シリコン系防水剤より優れた防水性および洗濯耐久性

柔らかい触感と帯電防止性を付与、起毛用の柔軟防水加工剤としても使用可能

Polyester、Cotton、Rayon、Nylonおよびその混紡素材に耐久性のある防水度を実現

弱カチオン性製品であり、アニオン系助剤との併用は推奨されない

広いpH範囲で使用可能だが、吸着率を高めるには弱酸性条件を推奨

一般的な加工方法と同様に水で希釈して使用し、Drying–Curing工程を行う

SPECIFICATIONS

性状は乳白色エマルションであり、pHは2.0～6.0、 イオン性はWeak Cationicです。 比重は0.99±0.01、固形分は25±1.0%で、 冷水に容易に希釈されます。

HOW TO USE

生地別の推奨使用量および加工条件は以下の通りです。

Fabric Padding Tentering
Cotton 30~80 g/L 170℃ x 180sec
T/C, T/R 30~60 g/L 180℃ x 180sec
C/N 30~60 g/L 170℃ x 120sec
Nylon 30~60 g/L 170℃ x 120sec
N/PC, N/C 30~60 g/L 170℃ x 120sec

最適な性能を得るためには、生地に浸透剤・染色助剤・柔軟剤・界面活性剤などの不純物が 残らないよう十分に前処理を行う必要があり、生地のpHは5～6の範囲に調整し、 7を超えないようにすることで防水度の低下やgum-up問題を防ぐことができます。

1回の処理で性能が不十分な場合は2～3回再加工します。

ADDITIONAL NOTES

優れた洗濯耐久性が必要な場合はERUSAM Cross-Linker（架橋剤）との併用を 推奨し、推奨配合はECOGUARD-WR 100pt + ECOGUARD-CL 10～15pt （防水剤に対して10～15%）です。

分散染料で染色された生地に防水処理を行う場合、昇華堅牢度が低下することがあるため、 昇華堅牢度の優れた染料を選択することをお勧めします。

PACKAGING & STORAGE

包装はIBC Tank単位で行われ、直射日光を避け、密封した状態で 5～30℃の環境で保管する必要があります。
